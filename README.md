# Calculator
My first calculator project I worked in Visual studio code.
A modern, minimalist web calculator with a glassmorphism design.

## 🚀 Features
* **Standard Math**: Addition, subtraction, multiplication, and division.
* **Special Functions**: Dedicated squaring ($x^2$) functionality.
* **Logic**: Safety checks for division by zero and multiple operators.

## 🛠️ Tech Stack
* **Frontend**: HTML5 and CSS3 (using Grid and Backdrop-filter for the "glass" effect).
* **Logic**: JavaScript (ES6).
